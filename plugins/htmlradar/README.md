# HTMLRadar for Claude Code

HTMLRadar turns a web-page document into a link you control: only the people you choose can open it, you see who read it and which sections they stayed on, and it stays current on the same link.

This plugin connects Claude Code to HTMLRadar. Your agent publishes the page, checks who read it and updates it, while you decide who gets in. Readers need no account and nothing to install.

## Install

```
/plugin marketplace add htmlradar/htmlradar-mcp
/plugin install htmlradar@htmlradar
```

Then run /mcp, choose htmlradar and sign in. There is one approval and no key.
